## 从官方 SDK 压缩包恢复并构建

输出目录必须是**尚不存在**的新目录，而且路径要短：CMake 中间文件的完整路径会超过 Windows 的 260 字符上限，放在很深的目录下会构建失败。

```powershell
python ./准备工程.py --sdk-zip '<SDK 下载目录>/STM32C5-MCU-HAL2.1.0_12-08-2026_06-37-21.zip' --out D:/C5_46_work
./构建工程.ps1 -ProjectRoot D:/C5_46_work -Config Debug -Variant prod
./构建工程.ps1 -ProjectRoot D:/C5_46_work -Config Debug -Variant test
```

Release 把 `-Config Debug` 换成 `-Config Release`。脚本先核对压缩包和 15 个改写文件的哈希，再解压官方子集并覆盖改写文件；只构建，不接板、不擦写。

作者本机自测（2026-10-21）：按上面的步骤恢复到工作目录下的新目录，正式版和测试变体两套 Release 构建 0 警告，`firmware.bin` 与 `固件/` 下对应文件逐字节相同。

## 上板前

1. 先备份配置页：`STM32_Programmer_CLI -c port=SWD -u 0x0803E000 0x2000 cfg_backup.bin`。
2. 下载正式版或测试变体，起始地址 0x08000000。不要做全片擦除，不要改选项字节。
3. 串口终端 115200、8N1、无流控，行尾 CR、LF 或 CRLF 都可以。上电先看到一行 `BOOT …`。
4. 若 BOOT 行显示外来记录占满了页、`SAVE` 回 `ERR FULL`，确认备份后擦第 31 页：`STM32_Programmer_CLI -c port=SWD -e 31`。

上面三条 CLI 命令的参数按本机 STM32CubeProgrammer 2.23.0 的 `--help` 核对，本轮没有连板执行。

## 命令

|命令|何时可用|成功回复|
|---|---|---|
|HELP|任何时候|OK HELP …|
|STATUS|任何时候|STATUS state=… 一行，最长 251 字节|
|START|STOP 时|OK START；运行中回 OK RUNNING；FAULT 回 ERR BUSY|
|STOP|任何时候|OK STOP|
|TH low high|STOP 时|OK TH low high；0 ≤ low < high ≤ 4095|
|SAVE|STOP 时|OK SAVE seq=… slot=…；同值 OK SAME|
|TIME YYYY-MM-DD HH:MM:SS|STOP 时|OK TIME；2000～2099 年的合法日期|

错误回复：ERR CMD（未知命令）、ERR FORMAT、ERR RANGE、ERR BUSY（状态不允许）、ERR LONG（一行超过 32 字节）、ERR FULL、ERR FLASH、ERR VERIFY、ERR RTC。状态变化另有 `EV …` 行。

测试变体另有：`T MASK`、`T NOREQ`、`T ERR`、`T SEQ a b c d`、`T HANG`，作用见正文第 07 节。

## 调试器可读的变量

|变量|含义|
|---|---|
|g_app|状态、阈值、seq、相邻样本间隔最小/最大、miss、故障计数与原因、最近事件|
|g_term|串口收发字节数与丢弃计数|
|g_cfg_scan|配置页扫描结果：已用、有效、外来、坏、ECC、下一槽、最近序号|
|g_cfg_ecc_addr|第一次双 ECC 错误的 Flash 行号|
|g_iwdg_pr、g_iwdg_rlr|启动后读回的 IWDG 分频与重载值，预期 2 与 3999|
|g_stack_free_min|启动以来从未用到的栈字节数，每秒更新|

IWDG 在调试器暂停内核时不会停（#21 已实测），停核超过约 2 s 就会复位。读变量用 #21、#32 的附着方式，或用测试变体专门测复位。
