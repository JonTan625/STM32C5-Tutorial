# 项目三状态与模块接口：参考填写

状态：接口草案，尚无固件。名称描述模块责任，不是可链接的实现。

## 三个状态

|当前状态|事件|下一状态|动作|
|---|---|---|---|
|启动|初始化完成|记录|快照复位原因；扫描日志找续写位置；读 BKP2R 周期；打印 BOOT 行；启动 IWDG 与唤醒定时器|
|记录（睡着）|RTC 唤醒|记录（醒着）|喂狗；采样；写记录；回 Stop1|
|记录（睡着）|PA3 下降沿|命令|恢复 144 MHz；重配 USART2；回 READY|
|命令|任意命令|命令|执行并回复；重置 60 s 空闲计时|
|命令|RTC 唤醒标志|命令|照常采样写记录（标记“命令模式中记录”）|
|命令|60 s 无命令或 SLEEP|记录（睡着）|关 USART2；PA3 改回 EXTI 输入；回 Stop1|
|任意|IWDG 超时|启动|硬件复位|

## 每次记录唤醒的顺序

```flow
RTC 唤醒（约 43 µs 后执行第一条指令，48 MHz）
↓
喂狗；清 WUTF（RTC 域保持可写，避开勘误 2.7.3）
↓
ADC 上电 → 等稳压器 → 校准 → 温度、VREFINT 各一次 → 深度掉电
↓
连读两次日历取时间 → 组 16 字节记录 → 当前页满则先擦下一页 → 写入并读回
↓
进 Stop1
```

## 模块接口

|模块|输入输出|责任与边界|
|---|---|---|
|Log_Init / Log_Append / Log_Read|记录结构；返回序号或错误|扫描、续写、换页擦除、读回；不碰 ADC 和 RTC|
|Sense_Sample|温度原始码、VREFINT 原始码、错误标志|只在 48 MHz、ADC 时钟为 HCLK 时调用；结束时 ADC 必须回到深度掉电|
|Time_Get / Time_Set|秒数或“无效”|BYPSHAD=1 连读两次；校时后写 BKP1R 标记|
|Power_Sleep / Power_WakeConsole|—|进 Stop1 前关外设并配置 PA3 EXTI；命令唤醒后恢复时钟与 USART2|
|Console_Poll|命令行与回复|只在命令模式；DUMP 按发送环余量节流|
|Health|复位原因、喂狗|唤醒与命令循环都要喂；周期上限 60 s 由 IWDG 120 s 决定|

## 命令

|命令|作用|回复|
|---|---|---|
|HELP|列出命令|OK HELP …|
|STATUS|周期、记录数、最旧/最新序号与时间、时间有效、最近温度|STATUS …|
|DUMP [n]|最近 n 条（缺省全部），CSV|多行，最后 OK DUMP n|
|TIME YYYY-MM-DD HH:MM:SS|校时|OK TIME / ERR RANGE|
|PERIOD s|周期 10～60 s|OK PERIOD s / ERR RANGE|
|CLEAR YES|擦除 16 页日志|OK CLEAR / ERR CONFIRM|
|SLEEP|立即回记录模式|OK SLEEP|

温度换算沿用 #30：先用 VREFINT_CAL 求 VDDA，再按 TS_CAL1（30 °C）、TS_CAL2（140 °C）两点插值。记录里只存原始码，换算在导出时做，以后换公式不用改记录。
