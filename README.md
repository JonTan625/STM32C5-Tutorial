# STM32C5-Tutorial

公众号「JonTan 嵌入式实验室」STM32C5 系列（#14 起）的配套代码与资料。板卡 NUCLEO-C542RC（STM32C542RC），软件基线 STM32C5 MCU HAL2.1.0、GCC 14.3.1。

## 怎么用

1. 从 ST 官方下载 STM32C5 MCU HAL2.1.0，解压到一个独立目录（保持原有目录层级）。
2. 打开对应篇目的目录，按文章或目录里的说明，把改写文件放回 SDK 里官方例程的对应位置。
3. 在官方例程的 `NUCLEO-C542RC/cmake` 目录执行 `cmake --preset debug_GCC_NUCLEO-C542RC`、`cmake --build --preset debug_GCC_NUCLEO-C542RC`（Release 把 debug 换成 release）。

每个目录只放改动或新增的文件、相对官方例程的差异、改动清单和使用说明，不含 ST 的完整 SDK。ELF 与 map 文件的调试信息带有作者本机路径，没有放进仓库，请按上面的步骤自行构建；部分篇目附了 BIN/HEX。

每篇做到哪一步（资料核对、构建、上板），以文章开头的“本篇状态”为准。
